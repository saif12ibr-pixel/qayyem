قيّم - تعليمات التنصيب (العربية)
================================

"قيّم" هو تطبيق ويب يقوم بتصحيح إجابات الطلاب النصية القصيرة باللغة العربية
باستخدام الذكاء الاصطناعي، ويكتب تغذية راجعة فردية لكل طالب بالعربية.


قبل أن تبدأ
-----------

اقرأ الملف PREREQUISITES/PREREQUISITES.txt. تحتاج إلى أمرين:

  ١. تنصيب Python 3.12 من الموقع python.org
     (ضع علامة على الخيار "Add python.exe to PATH" أثناء التنصيب)

  ٢. مفتاح API مجاني من https://aistudio.google.com/apikey
     (مجاني تمامًا ولا يتطلب بطاقة دفع)


الطريقة الأولى - الطريقة السهلة (ويندوز)
----------------------------------------

  ١. افتح مجلد SOURCE

  ٢. اضغط مرتين على الملف run.bat

  ٣. في التشغيل الأول سيُنشأ ملف باسم .env ثم يتوقف البرنامج.
     افتح الملف SOURCE\.env بواسطة Notepad، والصق المفتاح بعد
     GEMINI_API_KEY= ليصبح السطر مثلًا:

         GEMINI_API_KEY=AIzaSy...ضع-مفتاحك-هنا

     ثم احفظ الملف وأغلقه.

  ٤. اضغط مرتين على run.bat مرة أخرى.

  ٥. سيطلب منك إنشاء حساب المعلم. أدخل البريد الإلكتروني وكلمة مرور
     لا تقل عن ٨ أحرف.

  ٦. افتح المتصفح على العنوان http://127.0.0.1:5000 وسجّل الدخول.

  لإيقاف الخادم اضغط Ctrl+C في النافذة السوداء.
  لتشغيله مرة أخرى لاحقًا، اضغط على run.bat فقط.


الطريقة الثانية - التنصيب اليدوي (أي نظام تشغيل)
------------------------------------------------

افتح الطرفية (Terminal) داخل مجلد SOURCE ونفّذ الأوامر التالية:

  ١. إنشاء البيئة الافتراضية وتنشيطها:

         python -m venv .venv
         .venv\Scripts\activate          (ويندوز)
         source .venv/bin/activate       (ماك / لينكس)

  ٢. تحميل المكتبات اللازمة:

         pip install -r requirements.txt

  ٣. إنشاء ملف الإعدادات وإضافة المفتاح:

         copy .env.example .env          (ويندوز)
         cp .env.example .env            (ماك / لينكس)

     ثم عدّل الملف .env وضع مفتاحك في GEMINI_API_KEY

  ٤. إنشاء قاعدة البيانات:

         flask --app app init-db

  ٥. إنشاء حساب المعلم:

         flask --app app create-instructor

  ٦. تشغيل الخادم:

         flask --app app run

  ٧. افتح العنوان http://127.0.0.1:5000


طريقة استخدام التطبيق
---------------------

  ١. سجّل الدخول بالحساب الذي أنشأته.

  ٢. جهّز ملف CSV أو Excel يحتوي على عمودين: عمود لرقم الطالب وعمود
     للإجابة. يمكن كتابة العناوين بالعربية أو بالإنجليزية:

         الرقم الجامعي,الإجابة            أو        student_id,response

     يوجد ملف جاهز للتجربة في:
         SOURCE/sample_data/sample_responses.csv

  ٣. ارفع الملف، ثم الصق الإجابة النموذجية، ويمكنك إضافة معايير التصحيح
     (Rubric) اختياريًا. إضافة معايير التصحيح تُحسّن ثبات الدرجات بشكل
     ملحوظ، لذا يُنصح بكتابة سطر أو سطرين. حدّد الدرجة العظمى ثم اضغط
     على "Grade responses".

  ٤. سيظهر شريط تقدّم أثناء التصحيح، وتُحدَّث الصفحة تلقائيًا.

  ٥. بعد الانتهاء راجع الدرجات والتغذية الراجعة في الجدول، ثم اضغط
     "Download Excel" لتحميل النتائج.

     يحتوي ملف Excel على ورقتين: ورقة "Results" وفيها صف لكل طالب،
     وورقة "Assignment" وفيها الإجابة النموذجية ومعايير التصحيح
     والمتوسط والنموذج المستخدم.


تنبيه مهم - بيانات الطلاب لا تُحفظ
----------------------------------

تُحذف إجابات الطلاب ودرجاتهم عند تسجيل الخروج، أو عند انتهاء الجلسة بعد
٣٠ دقيقة من عدم النشاط. هذا الأمر مقصود، التزامًا بنظام حماية البيانات
الشخصية في المملكة العربية السعودية.

  ==> حمّل ملف Excel دائمًا قبل تسجيل الخروج.

إذا حاولت تسجيل الخروج ولديك نتائج لم تُحمّلها، سينبّهك التطبيق أولًا.


تشغيل الاختبارات
----------------

      python -m pytest

جميع الاختبارات (٦٥ اختبارًا) تعمل دون اتصال بالإنترنت ودون مفتاح API.


حل المشكلات الشائعة
-------------------

"Python is not installed, or only the Microsoft Store placeholder is"
      نصّب Python من الموقع python.org وليس من متجر مايكروسوفت، وضع
      علامة على "Add python.exe to PATH" أثناء التنصيب.

"GEMINI_API_KEY is not set"
      افتح الملف SOURCE\.env والصق المفتاح بعد GEMINI_API_KEY=

"API rejected the key"
      المفتاح غير صحيح أو مُلغى. أنشئ مفتاحًا جديدًا من
      https://aistudio.google.com/apikey

"Model ... was not found"
      المفتاح لا يملك صلاحية استخدام هذا النموذج. عدّل GEMINI_MODEL
      في الملف .env إلى نموذج متاح لحسابك.

"Rate limited by the API (429)"
      الخطة المجانية لها حد أقصى للطلبات. انتظر عدة دقائق، أو قلّل
      قيمة GRADING_BATCH_SIZE في الملف .env

"Could not find a response column"
      لم يتم التعرف على عناوين الأعمدة. أعد تسميتها إلى
      الرقم الجامعي و الإجابة، أو student_id و response

ظهور الحروف العربية بشكل غير مفهوم في ملف CSV
      أعد حفظ الملف من Excel بصيغة "CSV UTF-8 (Comma delimited)"

المنفذ مستخدم بالفعل (port in use)
      هناك برنامج آخر يستخدم المنفذ 5000. شغّل التطبيق على منفذ آخر:

         flask --app app run --port 5055
