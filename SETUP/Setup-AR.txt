قيّم - دليل التنصيب والإعداد والتهيئة (العربية)
==============================================

"قيّم" هو تطبيق ويب يقوم بتصحيح إجابات الطلاب النصية القصيرة باللغة العربية
باستخدام الذكاء الاصطناعي، ويكتب تغذية راجعة فردية لكل طالب بالعربية.


قبل أن تبدأ
-----------

اقرأ الملف PREREQUISITES/PREREQUISITES.txt. تحتاج إلى أمرين:

  ١. تنصيب Python بالإصدار 3.12 أو 3.13 أو 3.14 من الموقع python.org
     (ضع علامة على الخيار "Add python.exe to PATH" أثناء التنصيب)

  ٢. مفتاح API لنموذج الذكاء الاصطناعي. المزوّد الافتراضي Google Gemini
     مجاني ولا يتطلب بطاقة دفع:
     https://aistudio.google.com/apikey


الطريقة الأولى - الطريقة السهلة (ويندوز)
----------------------------------------

  ١. افتح مجلد SOURCE

  ٢. اضغط مرتين على الملف run.bat وسيقوم بما يلي:
       - إنشاء البيئة الافتراضية (.venv)
       - تحميل المكتبات اللازمة
       - إنشاء ملف الإعدادات .env من الملف .env.example
       - إنشاء قاعدة البيانات
       - تشغيل الخادم وفتح المتصفح على صفحة إنشاء الحساب

  ٣. أنشئ حساب المعلم من صفحة إنشاء الحساب: الاسم الكامل والبريد الإلكتروني
     وكلمة مرور لا تقل عن ٨ أحرف.

  ٤. أضف مفتاح الذكاء الاصطناعي بإحدى طريقتين:
       أ) من داخل التطبيق: افتح صفحة الإعدادات، واختر المزوّد (Gemini افتراضيًا)،
          والصق المفتاح، ثم اضغط "اختبار الاتصال". يُحفظ المفتاح مشفّرًا
          ويخص حسابك فقط.
       ب) لجميع المستخدمين على هذا الخادم: افتح الملف SOURCE\.env بواسطة
          Notepad، والصق المفتاح بعد GEMINI_API_KEY= ثم احفظ الملف،
          وأوقف run.bat وشغّله من جديد.

  لإيقاف الخادم اضغط Ctrl+C في النافذة السوداء.
  لتشغيله لاحقًا اضغط مرتين على run.bat. في كل تشغيل تُحمَّل أي مكتبات جديدة
  وتُحدَّث قاعدة البيانات مع الاحتفاظ بجميع الحسابات والمواد وبنوك الأسئلة.


الطريقة الثانية - التنصيب اليدوي (أي نظام تشغيل)
------------------------------------------------

افتح الطرفية (Terminal) داخل مجلد SOURCE ونفّذ الأوامر التالية:

  ١. إنشاء البيئة الافتراضية وتنشيطها:

         python -m venv .venv
         .venv\Scripts\activate          (ويندوز)
         source .venv/bin/activate       (ماك / لينكس)

  ٢. تحميل المكتبات اللازمة:

         pip install -r requirements.txt

  ٣. إنشاء ملف الإعدادات:

         copy .env.example .env          (ويندوز)
         cp .env.example .env            (ماك / لينكس)

     ويمكنك وضع المفتاح في GEMINI_API_KEY داخل الملف .env (انظر الإعدادات أدناه).

  ٤. إنشاء قاعدة البيانات:

         flask --app app init-db

     تنبيه: هذا الأمر يحذف قاعدة البيانات الموجودة. نفّذه مرة واحدة فقط.

  ٥. تشغيل الخادم:

         flask --app app run

  ٦. افتح العنوان http://127.0.0.1:5000/signup وأنشئ حساب المعلم.
     (إذا كان إنشاء الحسابات معطّلًا، أنشئ الحساب من الطرفية بالأمر:
      flask --app app create-instructor)


الإعدادات (ملف .env)
--------------------

جميع الإعدادات موجودة في الملف SOURCE/.env وأهمها:

  GEMINI_API_KEY          مفتاح Gemini لجميع المستخدمين (اختياري إذا أضاف كل
                          معلم مفتاحه من صفحة الإعدادات)
  GEMINI_MODEL            نموذج Gemini المستخدم
  OPENAI_API_KEY,         مفاتيح المزوّدين المدفوعين الاختياريين
  ANTHROPIC_API_KEY,
  DEEPSEEK_API_KEY
  SECRET_KEY              يوقّع الجلسات ويشفّر المفاتيح المحفوظة. اجعله قيمة
                          عشوائية طويلة قبل أول استخدام؛ تغييره لاحقًا يجعل
                          المفاتيح المحفوظة غير قابلة للقراءة، ويجب على المعلمين
                          إدخالها من جديد في صفحة الإعدادات.
  SIGNUP_ENABLED          1 = يستطيع المعلمون إنشاء حسابات (افتراضي)،
                          0 = الحسابات تُنشأ فقط بالأمر create-instructor
  SIGNUP_EMAIL_DOMAINS    حصر إنشاء الحسابات في نطاقات بريد معينة، مثل seu.edu.sa
  SESSION_TIMEOUT_MINUTES مدة عدم النشاط قبل تسجيل الخروج (افتراضيًا 30 دقيقة)
  GRADING_BATCH_SIZE      عدد الإجابات في كل طلب للذكاء الاصطناعي (افتراضيًا 10)
  MAX_ROWS                أكبر عدد صفوف مقبول في الملف (افتراضيًا 500)

أعد تشغيل الخادم بعد تعديل الملف .env


طريقة الاستخدام
---------------

  ١. سجّل الدخول.

  ٢. (اختياري) افتح صفحة "المواد" وأضف مادة. لكل مادة إرشادات تصحيح وبنك
     أسئلة مقسّم إلى: الواجب، الاختبار القصير، اختبار منتصف الفصل، الاختبار النهائي.
     يمكن كتابة الأسئلة يدويًا أو استيرادها من ملف Word للاختبار.

  ٣. افتح صفحة "تصحيح جديد" وجهّز الإجابات. يُقبل نوعان من الملفات:

       أ) ملف للفصل كاملًا (CSV أو Excel أو جدول في Word) فيه عمود للرقم
          الجامعي وعمود للإجابة. تعمل العناوين بالعربية أو الإنجليزية:

              الرقم الجامعي,الإجابة        أو     student_id,response
              S220001,الإجابة الأولى...           S220001,الإجابة الأولى...

          للاختبار الكامل يُخصَّص عمود إجابة لكل سؤال.

       ب) أوراق إجابة: ملف .docx أو .pdf أو .txt لكل طالب. يُقرأ الرقم
          الجامعي من أعلى الملف أو من اسمه.

     يوجد ملف مثال جاهز في SOURCE/sample_data/sample_responses.csv
     والإجابة النموذجية له في SOURCE/sample_data/ideal_answer.txt

  ٤. أدخل الإجابة النموذجية (اكتبها، أو ارفع كتابًا أو شرائح كمادة مرجعية،
     أو اختر المادة لتحميلها من بنك الأسئلة)، والدرجة القصوى، ويمكنك إضافة
     معايير التصحيح وتقسيم الدرجة إلى أجزاء. إضافة معايير التصحيح تحسّن ثبات
     الدرجات بشكل واضح. ثم ابدأ التصحيح.

  ٥. يظهر شريط تقدّم أثناء التصحيح في الخلفية، ويمكنك مغادرة الصفحة والعودة لاحقًا.

  ٦. في صفحة النتائج يمكنك:
       - قراءة ملخص الفصل: المتوسط، وأفضل ٥ طلاب، والأعلى والأدنى، ومجموعات
         الطلاب (منخفض / متوسط / مرتفع)
       - الضغط على "مراجعة" لأي إجابة لتعديل الدرجة أو التغذية الراجعة
         (مع الاحتفاظ بالدرجة الأصلية من الذكاء الاصطناعي)
       - البحث عن طالب برقمه الجامعي
       - الضغط على "تنزيل ملف Excel" للفصل كاملًا، أو تنزيل ملف لطالب واحد من البحث

     ملف Excel للفصل يحتوي على ورقتين: "Results" (صف لكل طالب) و"Assignment"
     (العنوان والتاريخ والدرجة القصوى وعدد الإجابات والمتوسط والنموذج المستخدم
     والإجابة النموذجية ومعايير التصحيح).


مهم - لا يتم الاحتفاظ ببيانات الطلاب
------------------------------------

تُحذف إجابات الطلاب ودرجاتهم عند تسجيل الخروج أو عند انتهاء الجلسة بعد ٣٠ دقيقة
من عدم النشاط. هذا مقصود للالتزام بنظام حماية البيانات الشخصية في المملكة
العربية السعودية. أما المواد وبنوك الأسئلة فهي مادة تعليمية ويتم الاحتفاظ بها.

  ==> نزّل ملف Excel دائمًا قبل تسجيل الخروج.

إذا حاولت تسجيل الخروج ولديك نتائج لم تنزّلها، سيحذّرك التطبيق أولًا.


تشغيل الاختبارات
----------------

داخل مجلد SOURCE ومع تنشيط البيئة الافتراضية:

      python -m pytest

جميع الاختبارات (٦٥٦ اختبارًا) تعمل دون اتصال بالإنترنت ودون مفتاح API.


حل المشكلات
-----------

"Python is not installed, or only the Microsoft Store placeholder is"
      نصّب Python من python.org وليس من متجر مايكروسوفت، وضع علامة على
      "Add python.exe to PATH" أثناء التنصيب.

فشل تحميل المكتبات
      تأكد من الإصدار بالأمر python --version واستخدم 3.12 أو 3.13 أو 3.14.
      احذف المجلد .venv ثم شغّل run.bat من جديد.

"No API key is available ..." أو لا يبدأ التصحيح
      أضف مفتاحًا من صفحة الإعدادات، أو ضعه في GEMINI_API_KEY داخل
      SOURCE\.env ثم أعد تشغيل الخادم.

"API rejected the key (400/401/403)"
      المفتاح غير صحيح أو تم إلغاؤه. أنشئ مفتاحًا جديدًا واستخدم
      الإعدادات > اختبار الاتصال للتحقق منه.

"Model ... was not found"
      مفتاحك لا يستطيع استخدام هذا النموذج. اضغط "تحديث" في صفحة الإعدادات
      لعرض النماذج المتاحة لمفتاحك واختر أحدها.

"Rate limited by the API (429)"
      الخطة المجانية تحدّ من عدد الطلبات. انتظر بضع دقائق ثم أكمل التصحيح؛
      الإجابات المرفوعة محفوظة.

"Could not find a response column"
      لم يتم التعرف على عناوين الأعمدة. غيّرها إلى الرقم الجامعي والإجابة،
      أو إلى student_id و response.

ظهور النص العربي كرموز غير مفهومة في ملف CSV
      أعد حفظ الملف من Excel بصيغة "CSV UTF-8 (Comma delimited)".

المنفذ مستخدم من برنامج آخر
      برنامج آخر يستخدم المنفذ 5000. شغّل الخادم على منفذ مختلف:

         flask --app app run --port 5055
