QAYYEM - PREREQUISITES
======================

REQUIRED
--------

1. Python 3.12, 3.13 or 3.14
   https://www.python.org/downloads/
   During installation, tick "Add python.exe to PATH".

   Note: the "python" that ships with Windows from the Microsoft Store is only a
   placeholder and will not run this project. Install from python.org.

   Python 3.15 is still a pre-release and has not been tested.

2. An API key for the AI model (at least one)
   The default provider is Google Gemini, which has a free tier and needs no
   payment card:
      https://aistudio.google.com/apikey
   The key can be pasted into SOURCE/.env as GEMINI_API_KEY (shared by every
   instructor), or each instructor can add their own key under Settings in the
   application.

   Optional paid providers, chosen under Settings:
      OpenAI GPT-4o      https://platform.openai.com/api-keys
      Anthropic Claude   https://console.anthropic.com/settings/keys
      DeepSeek           https://platform.deepseek.com/api_keys

3. A modern web browser
   Chrome, Firefox, Edge or Safari.

4. Internet access
   Needed while installing the dependencies and while grading, because the AI
   model runs as a cloud service.


INSTALLED AUTOMATICALLY
-----------------------

These are fetched by run.bat (or by "pip install -r requirements.txt") and do
not need to be installed by hand:

   Flask 3.0.3           web framework
   pandas 2.3.3          CSV and Excel parsing
   openpyxl 3.1.5        Excel file reading and generation
   requests 2.32.3       HTTP client for the AI providers
   python-dotenv 1.0.1   reads configuration from .env
   cryptography 43.0.1   encrypts instructors' API keys (Fernet)
   anthropic 1.9.0       Anthropic Claude client
   pypdf 5.1.0           reads PDF answer papers and reference material
   pytest 8.3.2          test runner


NOT REQUIRED
------------

   No database server. The project uses SQLite, a single file created
   automatically at SOURCE/instance/qayyem.sqlite3.

   No Node.js, npm or build step. The interface is server-rendered, and
   Bootstrap 5 and the IBM Plex Sans Arabic font are bundled in
   SOURCE/static/vendor, so the pages work without a CDN.

   No Microsoft Office. Word, PowerPoint and Excel files are read and written
   by Python libraries.


TESTED ON
---------

   Windows 11 Pro (10.0.26200), Python 3.12.10
   AMD Ryzen 7 5700X, 16 GB RAM

   The full test suite (656 tests) also passes on Linux with Python 3.12,
   3.13 and 3.14. It runs fully offline and needs neither an API key nor
   internet access.
